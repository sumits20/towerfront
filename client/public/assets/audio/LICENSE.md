# Audio asset licence register

**PLACEHOLDER AUDIO — not sourced from Kenney.nl or any third party.**

Every `.wav` file in this folder is a short procedurally-synthesized placeholder
(sine tones / filtered noise bursts generated by a one-off Node script), created
because this development environment did not have network access to download
real assets at the time these were added. None of it is derived from, or
claims to be, Kenney.nl's CC0 "Interface Sounds," "Impact Sounds," or "Sci-Fi
Sounds" packs referenced by the build plan (section 9) — do not represent it
as such.

**Replace every file below with real CC0-licensed audio before shipping.**
Kenney.nl (https://kenney.nl/assets, CC0) is the recommended source per the
build plan; update this file with the real pack name + license for each file
once replaced.
